# Product Spec: Notes & Activities (Phase 2)

## Goal

Enable sales users to log notes on deals and contacts, building an activity timeline.

## User Stories

- As a sales user, I can add a note to a deal or contact.
- As a sales user, I can categorize a note as: general, call, meeting, or email.
- As a sales user, I can view all notes on a deal's detail page in chronological order.
- As a sales user, I can edit or delete my own notes.
- As a sales user, I can see a unified activity timeline on a deal detail page (notes + stage changes + tasks).

## Acceptance Criteria

1. Note CRUD works from UI and API.
2. Notes display in chronological order on deal and contact detail pages.
3. Note type is shown with an appropriate icon (phone for call, calendar for meeting, etc.).
4. Activity timeline aggregates notes, deal stage changes, and task completions.
5. Permissions control access (own vs others' notes).
6. Full test coverage.
